# FinancersHub

Laravel publication and editorial studio for educational finance content.

## Development

- PHP compatibility currently remains 8.1 / Laravel 10. The supported-runtime/security upgrade is still a separate unresolved launch requirement; this refactor does not change it.
- Install PHP dependencies with `composer install` and JavaScript dependencies with `npm ci`.
- Configure `.env` and the existing MySQL database. Keep credentials out of version control.
- Run `php artisan migrate`, then `npm run build`.
- Start the application using your PHP web server with `public/` as its document root. For local Vite development run `npm run dev` alongside the PHP server.
- Never run `migrate:fresh` or demo seeders against a populated production database.

## Frontend

Bootstrap 5.3 is installed through npm and compiled selectively with Sass. Vite is the sole asset pipeline. The application uses Bootstrap form controls, buttons, breadcrumb structure, pagination, alerts and grid primitives with a custom FinancersHub theme. Typography, editorial layouts, colors and bespoke reading/dashboard components intentionally remain themed CSS.

- `resources/css/bootstrap/`: selected Bootstrap imports and variable configuration.
- `resources/css/theme/`: readable brand/layout styles; edit these sources, not build output.
- `resources/css/{publication,studio,login}.scss`: stylesheet entrypoints.
- `resources/js/`: page behavior and calculator source modules.
- `public/build/`: fingerprinted deployable Vite output, generated by `npm run build`.
- `public/assets/`: static images and brand artwork.
- `public/uploads/`: managed media; include it in deployment and backups separately from Git.

No Bootstrap CDN, icon font or full Bootstrap JavaScript bundle is required. Existing native disclosure widgets and application JavaScript handle interactions.

## Application organization

- `routes/web.php`: canonical public endpoints and admin route group.
- `routes/auth.php`: staff sign-in/out.
- `routes/admin.php`: authenticated studio operations.
- `routes/legacy.php`: compatibility aliases and permanent redirects for old URLs.
- `app/Http/Controllers/Admin/`: admin-only controllers.
- `app/Services/`: publication behavior, article HTML, maintenance and delivery services.
- `resources/views/publication/`: database-backed public pages.
- `resources/views/pages/`: informational pages.
- `resources/views/admin/`: active editorial screens.
- `resources/views/layouts`, `partials`, `components`: shared page structure and reusable components.
- `resources/views/errors`, `auth`, `mail`, `pagination`: purpose-specific templates.

## Checks

```text
npm run build
npm run format:assets
php artisan test
node --test tests/savings-math.test.mjs
php vendor/bin/pint --test
php artisan financershub:preflight
```

Preflight checks configuration only and is expected to fail for a local, non-indexable environment. Build assets before page-rendering integration tests, which verify the real compiled paths.
