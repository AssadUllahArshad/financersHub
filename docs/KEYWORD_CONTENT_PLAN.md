## Publishing workflow

1. Choose one principal reader question per URL, plus closely related supporting questions. Reuse the existing mapped page rather than publishing a near-duplicate targeting a wording variation.
2. Write a useful title/H1 and description that accurately describe the page. Use related terms naturally; do not force repetitions into text or image alt descriptions.
3. Check primary sources and calculations, label examples, and complete editorial review. Add sources and truthful author/disclosure details through the existing editor.
4. Keep both remaining articles and all new content as drafts until approval. Publish a reviewed Spanish translation through Article languages; otherwise English fallback remains explicit.
5. Add contextual links only to public destinations. Calculator links can go live now. Add related-article links after the targets are published.
6. After domain verification/indexing, use Search Console query and page reports to choose improvements based on actual impressions/clicks. Evaluate English and Spanish URLs separately.
